# CS50-PROBLEM-SET-5

My solutions for CS50x Problem Set 5, implemented in C language:

* **inheritance.c:** A program that simulates the genetic inheritance of blood types across generations using dynamic memory allocation and recursive structures.
* **speller (dictionary.c and dictionary.h):** A program that implements a spell-checker using a hash table to load dictionaries into memory, check words, and manage memory dynamically.
