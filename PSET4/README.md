# CS50-PROBLEM-SET-4

My solutions for CS50x Problem Set 4, implemented in C language:

* **volume.c:** A program that modifies the volume of a WAV audio file by scaling sample values.
* **filter.c (and helpers.c):** A program that applies image processing filters (grayscale, reflection, blur, and edges) to BMP files.
* **recover.c:** A program that recovers deleted JPEG images from a forensic memory card image.
