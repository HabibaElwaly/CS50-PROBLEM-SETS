# CS50-PROBLEM-SET-3

My solutions for CS50x Problem Set 3, implemented in C language:

* **plurality.c**: A program that runs a plurality election, determining the winner based on the highest number of votes.
* **runoff.c**: A program that runs a runoff election, implementing ranked-choice voting with elimination rounds.
* **sort**: An analysis of various sorting algorithms (Bubble, Selection, and Merge Sort) to determine their efficiency and complexity through empirical testing.
