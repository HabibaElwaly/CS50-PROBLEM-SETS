# CS50-PROBLEM-SET-2

My solutions for CS50x Problem Set 2, implemented in C language:

* **scrabble.c** : A program that determines which of two words wins a game of Scrabble, based on standard letter values.
* **readability.c** : A program that computes the approximate reading grade level needed to comprehend some text, using the Coleman-Liau index.
* **substitution.c** : A program that enables you to encrypt messages using a substitution cipher based on a provided 26-character key.
