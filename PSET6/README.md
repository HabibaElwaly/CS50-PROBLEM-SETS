# CS50-PROBLEM-SET-6

My solutions for CS50x Problem Set 6, implemented in Python language:

* **Hello**: A program that prompts a user for their name and then greets them.
* **Mario (less & more)**: Programs that recreate the classic half-pyramids using hashes for blocks, implemented in Python.
* **Cash / Credit**: Programs that calculate the minimum number of coins needed to change and validate credit card numbers using Luhn's Algorithm.
* **Readability**: A program that computes the approximate grade level needed to comprehend some text using the Coleman-Liau index.
* **DNA**: A program that identifies a person based on their DNA sequence using STR counts and CSV databases.
